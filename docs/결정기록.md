# 결정기록

## 2026-11-05 컨셉
- 결정: 식당 주방에서 삶은 계란을 깨고 까는 놀이. 벽걸이 TV에 유튜브를 틀어 두고 노동하듯 반복한다.
- 누가: 사용자. 과일 깎기·썰기(veggie-cut)가 어설프다는 평가 뒤 컨셉 자체를 바꿈. veggie-cut은 저장소·배포·폴더 모두 지움.
- 요구사항 답변(내 추천을 사용자가 고름): 새 저장소 + 새 주소, 고정 시점 + 진짜 유튜브 플레이어, 껍질 조각을 잡아 떼기. 반복 요소는 깐 개수·오늘 기록, 깔끔하게 깐 판정, 주방 소리, 가벼운 주문 네 가지 모두(사용자 선택).

## 2026-11-05 시안은 3D로
- 결정: 시안 세 개 모두 three.js 3D 장면으로 만든다. 카메라는 한 자리에 고정한다.
- 누가: 사용자("2d말고 3d인걸 생각했는데").
- 버린 시도: 처음엔 2D 그림(SVG, 캔버스) 시안 세 개를 만들었다. 기획서에 3D라고 적어 두고도 시안을 빨리 내려고 2D로 그린 내 실수라 모두 지웠다. 그때 만든 조각 떼기·내리치기 판정 방식은 3D 시안에 그대로 옮겼다.
- 레퍼런스: Perfect Peel(조작 하나, 시간 압박 없음), Egg Peeling iOS(깨기→들기→버리기 순서, '너무 반복적'이라는 리뷰), TV Simulator(방 안 TV에 아무 영상), Job Simulator·Cooking Simulator(주방 물리 손맛, 실사와 손그림 두 방향).
- 시안: A 따뜻한 실사풍 식당 주방(안전), B 툰 셰이딩 심야 분식집(독특), C 밝은 주방 + 멈춤·흔들림·부스러기 연출(능동). 셋 다 같은 3D 코드에 생김새와 연출만 바꿨다.
- 고른 결과: C(밝은 주방 + 손맛 연출). 사용자 결정.

## 2026-11-05 금 모양과 껍질 떼는 규칙
- 사용자 피드백: "계란이 금가는 패턴이 너무 다 똑같다", "아무 곳이나 눌러도 안 보이는 뒷면까지 까진다".
- 원인 1: 집을 때 계란을 늘 똑바로 세워서 매번 바닥 끝(같은 곳)으로 부딪혔다. 조각도 계란 전체에 고르게 나눠서 세게 치든 약하게 치든 모양이 비슷했다.
- 원인 2: 껍질 재질이 양면이라 클릭 광선이 흰자를 뚫고 뒷면 조각에도 맞았다. 그리고 멀쩡한 조각도 바로 뗄 수 있었다.
- 결정(내 제안, 사용자 피드백 기준):
  - 집을 때마다 쥐는 각도를 무작위로 바꾸고, 내리칠 때 가장 아래에 있던 점을 '부딪힌 곳'으로 삼는다.
  - 부딪힌 곳 근처는 잘게, 멀수록 크게 나눈다. 세게 칠수록 벌어진 범위가 넓다(벌어짐 → 실금 → 멀쩡 세 단계).
  - 클릭은 흰자까지 같이 검사해서 맨 앞에 맞은 것만 본다. 껍질은 벌어진 조각, 또는 이미 깐 곳과 모서리가 닿은 조각만 뗄 수 있다. 멀쩡한 곳을 누르면 조각이 떨리고 "아직 단단히 붙어 있어요"가 뜬다.
  - 가운데로 가져올 때 금 간 곳이 카메라를 보게 돌려 준다.
- 버린 방법(앞면 판정): 조각 방향(법선)만 보고 앞면을 판정하는 방식. 계란을 돌리는 중간 각도에서 흰자에 가려진 조각이 잡힐 수 있어서, 흰자와 함께 광선을 쏘는 방식을 골랐다.

## 2026-11-05 까는 손맛: 문질러 까기
- 사용자 피드백: 까는 방식이 "답답하다".
- 내가 본 원인: 한 번 끌 때 한 조각만 떨어졌다. 깐 곳이 뒤로 가면 매번 직접 돌려야 했다. 조각을 살짝 빗겨 누르면 계란이 돌아가 버렸다.
- 결정(내 제안):
  - 누른 채로 쓸면 손이 지나가는 뗄 수 있는 조각이 줄줄이 떨어진다.
  - 끄는 방향 쪽 옆 조각 2~3개가 막처럼 같이 딸려 온다.
  - 손을 떼면 다음에 깔 곳이 앞으로 오게 350ms 동안 자동으로 돌린다.
  - 정확히 못 눌러도 36px 안의 뗄 수 있는 앞쪽 조각을 잡아 준다.
  - 흰자 패임은 처음 잡을 때 아주 빠르게(3.2px/ms 넘게) 뜯을 때만 생긴다. 문지르는 중에는 생기지 않는다.
- 확인: 자동 테스트에서 남은 조각 12개를 6번 문질러서 다 깠다. 헛손질은 0번이었다. 바꾸기 전에는 10~12번 문질렀고 그중 절반 가까이가 헛손질이었다.

## 2026-11-05 흰자 패임 판정 빼고 본 작업 시작
- 결정: 흰자 패임과 '완벽' 판정을 뺀다. 시안 C의 생김새와 문질러 까기 방식 그대로 본 작업을 만든다.
- 누가: 사용자("흰자 패임 이런건 그냥 없애고 일단 이대로 한번 만들어보자").
- 따라 바뀐 것: 기획서 필수 기능에서 '깔끔하게 깐 판정'을 범위 밖으로 옮겼다. 'n연속' 표시도 완벽 판정에 기대던 것이라 같이 뺐다.

## 2026-11-05 세로 화면(폰) 배치
- 문제: 시안 그대로 옮기니 폰 세로 화면에서 계란 더미와 접시가 화면 밖으로 나가 계란을 집을 수 없었다(테스트에서 발견).
- 결정(내 판단): 화면 비율에 따라 카메라와 까는 자리를 바꾼다.
  - 세로 화면은 카메라를 뒤로 물리고 시야를 넓혀 더미·그릇·접시가 다 들어오게 한다. 까는 계란은 카메라 앞으로 당기고 3.6배로 키워 손가락으로 잡기 쉽게 한다.
  - 가로·세로 사이(태블릿 등)는 두 배치를 비율에 따라 섞는다.
  - 터치로 누를 때는 근처 조각을 잡아 주는 범위를 36px에서 48px로 넓힌다.
- 버린 방법: 세로 화면에서만 더미·접시를 가운데로 모으기. 물건 위치가 화면마다 달라져 코드가 복잡해지고, 주방이 비좁아 보였다.

## 2026-11-06 내리친 직후 계란이 안 눌리던 버그
- 증상: 계란을 내리친 뒤 바로 누르면 가끔 가운데로 오지 않았다. 느린 화면(테스트용 소프트웨어 렌더링)에서 자주 났다.
- 원인: 클릭 판정은 '마지막으로 그린 프레임'의 물체 위치를 쓴다. 방금 생긴 금 간 계란은 아직 한 번도 안 그려져서 위치가 원점에 있었다. 화면 흔들림도 클릭 광선에 섞여 있었다.
- 결정: 클릭을 판정하기 직전에 물체 위치를 한 번 갱신하고, 흔들림이 없는 원래 시점으로 광선을 쏜다. 흔들림은 프레임 수가 아니라 시간 기준으로 0.3초쯤에 잦아들게 했다.
- 확인: 데스크톱 크기 자동 테스트에서 고치기 전에는 3번 중 3번 실패했고, 고친 뒤에는 3번 다 성공했다.

## 2026-11-08 모바일 웹을 먼저 보기로 (세로 폰은 TV를 위쪽 띠로)
- 요청: "sky-doodle도 그렇고 egg-peel도 그렇구 모바일 웹에 최적화 되게끔 수정해줘 타겟을 모바일 웹 쪽으로 하게"
- 본 것: 390×844 세로 화면에서 벽걸이 TV가 화면 가운데 작게(폭 약 170px) 떠서 영상이 거의 안 보였다. 아래 버튼은 높이 30px 남짓, 링크 칸 글자는 13px이라 iOS에서 입력할 때 화면이 확대된다. 844×390 가로 폰에서는 안내 문구가 가운데 아래에 길게 떠 장면을 가렸다.
- 결정 (사용자가 고름, 모두 내 추천안):
  - 세로 폰 TV: 화면 위쪽에 폭 가득 16:9 띠로 빼고, 주방은 그 아래. 가로·PC는 벽걸이 TV 그대로.
  - PC 화면: 모바일 우선, PC는 지금처럼 넓게.
  - 홈 화면에 추가(PWA): 넣는다. 매니페스트·아이콘만.
  - 배포: 화면을 보여 주고 확인받은 뒤에.
- 내가 정한 세부: 띠 높이는 화면의 32%까지(작은 폰에서 주방이 너무 줄지 않게). 띠가 생기면 벽 TV 모형을 숨기고 카메라 시선을 작업대로 내렸다. 처음엔 기존 세로 배치를 그대로 썼는데, TV가 빠진 빈 벽이 화면 절반을 차지해 계란이 작아 보였다. 3D 영역의 위쪽 여백을 `VIEW` 한 곳에 두고 클릭 판정·화면 좌표가 모두 그 값을 쓰게 했다.
- 확인: 세로 화면 틀(390×844)에서 띠 아래 계란을 끌어 까고 돌려 봤다. 손가락 위치와 벗겨지는 조각이 맞았다.

## 2026-11-09 impeccable 점검 뒤 고친 것들
- 요청: "저거로 내 sky 랑 egg 전체 점검해줘" (impeccable 스킬로 디자인 비평 + 기술 점검)
- 점검 방식: 서로 결과를 못 보는 에이전트 둘(디자인 리뷰 / 자동 탐지기·브라우저)로 돌리고 합쳤다. 점수는 디자인 21/32, 기술 11/20. 중요한 지적은 코드에서 직접 확인했다.
- 사용자 결정(픽): 폰 손맛 먼저, P1 + P2 전부 고치기.
- 고친 것과 근거:
  - 세로 폰에서 내리친 계란을 다시 누르는 단계가 반지름 5px 정확 일치라 헛탭이 났다 → 가운데가 비면 저절로 가운데로(단계를 없앰). 판정 반경만 넓히는 안도 같이 넣었다(가운데가 차 있을 때 쓰임).
  - 세로 폰 더미가 왼쪽 끝 75px 덩어리였다 → 카메라만 당기면 더미가 화면 밖으로 잘려서(직접 값 바꿔 확인), 세로 화면에서만 작업대 소품을 가운데로 모으고 카메라를 당겼다. 더미 폭 약 105px.
  - 영상 틀어 두는 놀이인데 3D가 늘 60fps → 가만히 있을 때 초당 12번, 탭 숨김 정지, 터치 기기 픽셀 배율 1.5. 완전히 멈추는 안은 냄비 김·숨 쉬는 계란이 뚝뚝 끊겨 버렸다.
  - 틀린 링크를 넣으면 입력이 지워졌다 → 남기고 오류 문장. 링크 바꾸기는 영상을 끄지 않고 위에 덮는 폼 + 취소.
  - 끝맺음이 약했다(흰 접시 위 흰 계란, 흰 토스트) → 민트 접시, 완료 도장·쪽지 날아가기, 진한 토스트.
  - 첫 안내가 두 단계를 한 문장에 담았다 → 지금 할 한 가지만.
- 다시 돌린 탐지기: 0건(튀어 오르는 곡선 지적은 부드러운 감속 곡선으로 바꿔 해결).
